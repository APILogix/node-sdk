Backend Integration & Remote Config

The Pulse SDK relies on a backend handshake during init() to retrieve ingestion URLs, configuration limits, and the billing Plan Tier. This document details the exact JSON payloads the backend must accept and return.

1. The Initialization Request (SDK → Backend)

When createSDK() is called, the SDK makes a POST request to the base URL (e.g. https://api.pulse.dev/v1/init).

Method: POST

Body:

{
  "apiKey": "pk_live_a1b2c3d4e5..."
}

Security Note: Body Only

API keys are never sent in headers like x-api-key. They are strictly passed in the JSON body for both initialization and event ingestion requests to prevent accidental logging by middleboxes or proxies.

2. The Initialization Response (Backend → SDK)

The backend must validate the API key, determine the organization's plan, and return the following JSON structure.

{
  "success": true,
  "projectId": "proj_abc123",
  
  "plan": "pro",
  "planFeatures": {
    "allowTracing": true,
    "allowMetrics": false,
    "maxBreadcrumbs": 200
  },
  
  "config": {
    "samplingRate": 1.0,
    "enableErrors": true,
    "enablePerformance": true,
    "maxRetries": 3,
    "maxPayloadBytes": 524288
  },
  
  "ingestion": {
    "endpoint": "https://ingest.pulse.dev/v1/events",
    "batchSize": 25,
    "maxQueueSize": 1000,
    "flushInterval": 1000
  }
}

3. Field Reference

Plan Gating (plan and planFeatures)

FieldTypeDescription
plan'free' | 'pro' | 'enterprise'Determines hard feature limits.
planFeatures.allowTracingbooleanCan the SDK start OpenTelemetry spans?
planFeatures.allowMetricsbooleanCan the SDK capture histograms/counters?
planFeatures.maxBreadcrumbsnumberCapacity of the O(1) Ring Buffer.

SDK Config (config)

FieldTypeDescription
samplingRatenumberFraction of events to send (0.0 to 1.0).
enableErrorsbooleanMaster kill-switch for error tracking.
maxPayloadBytesnumberIf a batch exceeds this, the SDK auto-splits it.

Ingestion Settings (ingestion)

FieldTypeDescription
endpointstringThe dedicated route for sending batched telemetry.
batchSizenumberHow many events to queue before flushing.
flushIntervalnumberTime in ms to wait before forcing a flush.

4. Failure Handling & Retries

If the backend returns a 4xx or 5xx response during initialization, the SDK implements an exponential backoff retry mechanism (max 5 attempts). If initialization permanently fails, the SDK falls back to a minimal "Free Plan" configuration and logs a structured warning.

Pulse SDK Features

The Pulse SDK is designed to be zero-config, with enterprise capabilities controlled securely via backend Plan Gating. Below is a detailed breakdown of all supported features.

🚨 Error Tracking & Crash Reporting

Free Tier+

Automatic capturing of unhandled exceptions and promise rejections with rich contextual data.

  • Deep stack trace parsing (V8, ESM, eval-aware).
  • SHA-256 fingerprinting for accurate error grouping.
  • Severity levels (info, warning, error, fatal).
  • Automatic attachment of local variables and async context.

🍞 Breadcrumb Timelines

Free Tier+ (Limits Apply)

An event timeline leading up to an error, implemented as a high-performance O(1) Ring Buffer.

  • Auto-tracks HTTP requests, DB queries, UI clicks, and navigations.
  • Free: max 50 breadcrumbs. Pro: 200. Enterprise: 1000.
  • Attached to every error to provide replication context.

🕸️ Distributed Tracing (OpenTelemetry)

Pro Tier+

Enterprise-grade distributed tracing built on OpenTelemetry primitives, fully integrated into the event pipeline.

  • Automatic W3C Trace Context injection and extraction (traceparent headers).
  • Ergonomic withSpan API for auto-closing scopes and capturing exceptions.
  • Automatic resource detection (OS, Hostname, Runtime version).
  • Parent-child span correlation across microservices.

📈 Custom Metrics

Enterprise Only

High-performance numerical telemetry ingestion for application monitoring.

  • Counters: Monotonically increasing values (e.g., requests, errors).
  • Gauges: Point-in-time values (e.g., active connections, memory heap).
  • Histograms: Statistical distributions (e.g., request latency).

🛡️ Security & PII Scrubbing

Free Tier+

Every event passes through a deep sanitization pipeline before it leaves the server.

  • Automatically scrubs Emails, Credit Cards, SSNs, and Phone Numbers via regex.
  • Redacts sensitive keys (password, secret, apiKey, authorization).
  • API keys are never sent in HTTP headers (embedded in JSON body only).

🚀 Transport Resilience

Free Tier+

Built to never crash the host application or cause memory leaks.

  • Circuit Breaker: 3-state (Closed, Open, Half-Open) protection against cascading ingest failures.
  • Batching & Compression: Gzip/Brotli compression based on plan limits.
  • Backoff Retries: Exponential jitter backoff on network failures.

🧩 Plugin System & Event Processors

Pro Tier+

Extensibility layer to mutate, enrich, or drop events dynamically.

  • Full lifecycle hooks: setup, processEvent, beforeSend, afterSend, teardown.
  • Fault isolation: A failing plugin will never break the main pipeline.
  • Pro allows up to 3 plugins. Enterprise allows unlimited.

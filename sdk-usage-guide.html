Pulse SDK Integration Guide

A step-by-step guide to installing and configuring the Enterprise Pulse SDK in your Node.js application.

1. Installation

npm install @vikasbaplawat1/pulse-sdk

2. Quick Start (Zero-Config)

The SDK operates on a Plan-Gating system. All features are enabled by default and are clamped to your billing plan remotely. Just provide your API key.

import { createSDK } from '@vikasbaplawat1/pulse-sdk'

// Must be the very first thing in your entry file
await createSDK({
  apiKey: process.env.PULSE_API_KEY
})

3. Framework Integrations

Express.js Implementation

Using the provided middleware ensures accurate request timing, error trapping, and W3C trace context extraction.

import express from 'express'
import { createSDK, monitorMiddleware, captureError, instrumentHttpClient } from '@vikasbaplawat1/pulse-sdk'

await createSDK({ apiKey: process.env.PULSE_API_KEY, service: 'api-gateway' })

// Enable auto-tracing for outbound HTTP requests (fetch / axios)
instrumentHttpClient()

const app = express()

// 1. Add monitor middleware BEFORE any routes
app.use(monitorMiddleware)

app.get('/users', (req, res) => {
    res.json({ ok: true })
})

// 2. Add error capturing middleware AFTER all routes
app.use((err, req, res, next) => {
    captureError(err, { context: { url: req.originalUrl } })
    res.status(500).send('Error')
})

app.listen(3000)

Fastify Implementation

Fastify is fully supported via a native plugin.

import Fastify from 'fastify'
import { createSDK, fastifyPulsePlugin } from '@vikasbaplawat1/pulse-sdk'

await createSDK({ apiKey: process.env.PULSE_API_KEY, service: 'order-service' })

const app = Fastify()

// Register the Pulse plugin globally
app.register(fastifyPulsePlugin, {
    ignorePaths: ['/health', '/ready'],
    captureHeaders: true
})

app.get('/orders', async (request, reply) => {
    return { status: 'processing' }
})

app.listen({ port: 3000 })

4. Using Core Features

Distributed Tracing (Spans)

Wrap critical operations in withSpan to automatically track duration, status, and exceptions.

import { withSpan } from '@vikasbaplawat1/pulse-sdk'

async function processPayment(amount) {
    return withSpan('stripe.charge', async (span) => {
        span.setAttribute('payment.amount', amount)
        
        const result = await stripe.charges.create({ amount })
        
        span.addEvent('charge_successful')
        return result
    })
}

Metrics & Telemetry

import { incrementCounter, recordHistogram } from '@vikasbaplawat1/pulse-sdk'

// Count business events
incrementCounter('orders.created', { region: 'us-east' })

// Track durations or distributions
recordHistogram('db.query.duration', 42.5, { table: 'users', unit: 'ms' })

Module Responsibilities

📦 Core

Handles the fundamental SDK lifecycle. Manages the initialization handshake with the backend, merges local options with remote configuration, enforces plan-based feature gates (Free/Pro/Enterprise), and provides the globally accessible AsyncLocalStorage context store.

🎣 Capture

Provides the ergonomic user-facing methods for manual instrumentation. Formats errors, normalizes messages, structures metrics (counters, gauges, histograms), and pipes them into the central event processing pipeline.

🔌 Instrumentation

Contains framework-specific integrations. Provides middlewares for Express and Fastify to automatically extract headers, start request spans, and track response times. Also includes auto-patching for the native Node.js http/https modules.

🕸️ Tracing

An enterprise-ready abstraction over OpenTelemetry. Manages span lifecycles, injects and extracts W3C traceparent headers for cross-service distributed tracing, and enriches spans with host/OS resource attributes.

🚚 Transport

The resilience layer. Implements bounded memory queues, batch processing, payload compression (gzip/brotli), a 3-state circuit breaker to prevent cascading failures, and exponential backoff retry logic.

Public API Exports (index.ts)

The following table lists everything exported by the SDK as a public contract.

Category Exports Description
Initialization createSDK, init, shutdown, flush Bootstraps the SDK and manages graceful shutdown. createSDK is the primary entry point.
Capture captureError, captureMessage, captureEvent Manually records errors and informational messages into the pipeline.
Metrics captureMetric, incrementCounter, setGauge, recordHistogram Records numerical data for aggregations and dashboards.
Tracing startSpan, withSpan, withSpanSync, getActiveSpan Creates and manages distributed tracing spans with automatic lifecycle management.
Context addBreadcrumb, getRequestContext, getTraceId Interact with the current AsyncLocalStorage context, adding timeline breadcrumbs.
Propagation extractTraceContext, injectTraceContext Manually parse and inject W3C trace headers for distributed microservices.
Integrations monitorMiddleware, instrumentHttpClient Plug-and-play middleware for Express and global HTTP patching.

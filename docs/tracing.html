Distributed Tracing

OpenTelemetry-based distributed tracing with W3C trace context propagation.

Architecture

The SDK integrates with OpenTelemetry to provide enterprise-grade tracing:

import { NodeTracerProvider } from '@opentelemetry/sdk-trace-node'
import { BatchSpanProcessor } from '@opentelemetry/sdk-trace-base'
import { AsyncLocalStorageContextManager } from '@opentelemetry/context-async-hooks'

// Custom exporter routes spans through SDK pipeline
class PipelineSpanExporter implements SpanExporter {
  export(spans: ReadableSpan[], resultCallback) {
    for (const span of spans) {
      const traceEvent = this.spanToEvent(span)
      processEvent(traceEvent) // Through event pipeline
    }
    resultCallback({ code: 0 })
  }
}

Tracer Initialization

export function initTracer(config: ResolvedSDKConfig): void {
  const resource = resourceFromAttributes({
    [ATTR_SERVICE_NAME]: config.service,
    [ATTR_SERVICE_VERSION]: config.release,
    [ATTR_DEPLOYMENT_ENVIRONMENT_NAME]: config.environment,
    'host.name': os.hostname(),
    'process.runtime.version': process.version,
  })

  provider = new NodeTracerProvider({
    resource,
    spanProcessors: [
      new BatchSpanProcessor(new PipelineSpanExporter(), {
        maxQueueSize: 2048,
        maxExportBatchSize: 512,
        scheduledDelayMillis: 5000,
      }),
    ],
  })

  const contextManager = new AsyncLocalStorageContextManager()
  contextManager.enable()
  provider.register({ contextManager })
}

Span Creation

// Start a new span
const span = startSpan('HTTP GET /api/users', {
  attributes: { 'http.method': 'GET', 'http.url': '/api/users' }
})

// Or use helper for automatic end
const result = await withSpan('db.query', async (span) => {
  span.setAttribute('db.system', 'postgres')
  return await db.query(sql)
}, { attributes: { 'db.statement': sql } })

PulseSpan API

export class PulseSpan {
  get spanId(): string
  get traceId(): string
  get isRecording(): boolean

  setAttribute(key: string, value: string | number | boolean): this
  setAttributes(attributes: Attributes): this
  addEvent(name: string, attributes?: Attributes): this
  recordError(error: Error, attributes?: Attributes): this
  setStatus(status: SpanStatus, message?: string): this
  end(endTime?: TimeInput): void
  addLink(link: SpanLink): this
}

Context Propagation

W3C Trace Context propagation for distributed tracing across services:

// Extract trace context from incoming request
export function extractTraceContext(headers): Context {
  const extracted = propagation.extract(otelContext.active(), headers, headerGetter)
  return extracted
}

// Inject trace context into outgoing request
export function injectTraceContext(headers: Record, ctx?: Context): void {
  propagation.inject(ctx ?? otelContext.active(), headers, headerSetter)
  // Also inject custom Pulse headers
  headers['x-pulse-trace-id'] = spanContext.traceId
  headers['x-pulse-span-id'] = spanContext.spanId
}

Supported Headers

  • traceparent - W3C Trace Context (primary)
  • tracestate - Vendor-specific baggage
  • x-pulse-trace-id - Pulse custom header
  • x-pulse-span-id - Pulse custom header
  • x-pulse-sampled - Sampling decision

Express Middleware Integration

// In your Express app
import { monitorMiddleware } from '@vikasbaplawat1/pulse-sdk'

app.use(monitorMiddleware()) // Auto-creates request context

The middleware:

  • Creates AsyncLocalStorage context per request
  • Extracts trace context from incoming headers
  • Creates request span with OTel attributes
  • Adds breadcrumbs for HTTP requests

HTTP Client Instrumentation

// Auto-trace outbound HTTP requests
import { instrumentHttpClient } from '@vikasbaplawat1/pulse-sdk'

instrumentHttpClient() // Call once at startup

// All http/https requests are now auto-instrumented
fetch('https://api.example.com/users') // Creates span automatically
  • Patches Node.js http/https modules
  • Creates client span for each request
  • Injects trace context headers
  • Records response status and duration

Span Lifecycle

  1. Created: Span started with name and optional attributes
  2. Recording: Attributes added, events recorded, errors captured
  3. Ended: Span finished, duration calculated
  4. Exported: Sent through BatchSpanProcessor to SDK pipeline

Pulse SDK Documentation

Enterprise-grade observability SDK for Node.js applications with error tracking, distributed tracing, metrics, and session monitoring.

⚠
Error Tracking
Capture exceptions with stack traces, fingerprinting, and automatic deduplication.
🔗
Distributed Tracing
OpenTelemetry-based tracing with W3C context propagation across services.
📈
Metrics
Counters, gauges, and histograms with client-side aggregation and percentiles.
📋
Breadcrumbs
Event timeline with ring buffer storage for debugging user sessions.
🛠
Sessions
Automatic session tracking with crash-free rate calculation.
🔒
Security
Automatic PII redaction, sensitive data masking, and plan-based access control.

Quick Start

npm install @vikasbaplawat1/pulse-sdk
import { createSDK, captureError } from '@vikasbaplawat1/pulse-sdk'

// Initialize the SDK
await createSDK({
  apiKey: process.env.PULSE_API_KEY,
  service: 'my-service',
  environment: 'production',
})

// Capture errors
try {
  await riskyOperation()
} catch (error) {
  captureError(error)
}

Architecture Overview

The SDK follows a modular architecture with clear separation of concerns:

  • Capture Layer: Entry points for errors, requests, messages, and metrics
  • Processing Pipeline: 14-stage event processing with normalization, sanitization, and enrichment
  • Transport Layer: Queue management, batch processing, circuit breaker, and retry logic
  • Instrumentation: Framework integrations (Express, Fastify) and auto-tracing
Version: This documentation covers Pulse SDK v2.0.0

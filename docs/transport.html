Transport System

Transport System

Complete documentation of the event queue, batch processor, circuit breaker, retry logic, and HTTP transport.

Event Queue

The EventQueue is a fixed-capacity ring buffer that stores events before batching:

export class EventQueue {
  private queue: Event[] = []
  private maxSize: number
  private droppedCount = 0
  private deadLetterCount = 0

  add(event: Event) {
    if (this.queue.length >= this.maxSize) {
      this.queue.splice(0, 1) // Evict oldest
      this.droppedCount += 1
    }
    this.queue.push(event)
  }
}
  • Drop Policy: Evicts oldest event when queue is full
  • Dead Letter: Tracks events moved to dead letter
  • Requeue: Failed events can be re-added to front
  • Filter: Pre-filter events based on config

Batcher

The batcher drains the queue at regular intervals and sends events in batches:

export function startBatcher(options?: BatcherOptions): void {
  batchSize = options?.batchSize ?? 100
  flushIntervalMs = options?.flushIntervalMs ?? 5000
  scheduleNextTick()
}

async function tick(): Promise {
  // Memory pressure check
  if (pressure.level === 'critical') return
  
  // Circuit breaker check
  if (!circuitBreaker.canExecute()) return
  
  // Rate limiter check
  if (!rateLimiter.tryAcquire()) return
  
  // Concurrent sends limit
  if (inFlightCount >= maxConcurrentSends) return

  const events = eventQueue.drain(batchSize)
  await sendEvents(events)
}

Batcher Guards

  • Memory Pressure: Skips sending when heap > 90%
  • Circuit Breaker: Skips when endpoint is down
  • Rate Limiter: Token bucket throttling
  • Concurrency Limit: Max N in-flight sends

Circuit Breaker

Prevents cascading failures when the ingestion endpoint is down:

export class CircuitBreaker {
  private state: CircuitState = 'CLOSED'
  private consecutiveFailures = 0
  private readonly failureThreshold = 5
  private readonly resetTimeoutMs = 30_000

  canExecute(): boolean {
    if (this.state === 'CLOSED') return true
    if (this.state === 'OPEN' && Date.now() - this.lastFailureTime >= this.resetTimeoutMs) {
      this.transitionTo('HALF_OPEN')
      return true
    }
    return this.state === 'HALF_OPEN'
  }
}

Retry System

Exponential backoff with retry budget to prevent retry storms:

export class RetryBudget {
  private inFlight = 0
  private readonly maxConcurrentRetries = 10

  tryAcquire(): boolean {
    if (this.inFlight >= this.maxConcurrentRetries) {
      return false // Budget exhausted
    }
    this.inFlight += 1
    return true
  }
}
  • Retry Budget: Max 10 concurrent retries across all operations
  • Exponential Backoff: Base delay 250ms, max 5s
  • Jitter: Random variation to prevent thundering herd
  • Retry-After: Respects server-provided Retry-After header

Rate Limiter

Token bucket algorithm for throttling batch sends:

const rateLimiter = new TokenBucketRateLimiter({
  capacity: 10,      // Burst of 10
  refillRate: 2,     // 2 tokens/sec
})

if (!rateLimiter.tryAcquire()) {
  return // Skip this tick
}

HTTP Transport

JSON-over-HTTP transport with compression support:

export async function sendEvents(events: Event[]) {
  for (const payload of createPayloads(events, apiKey, maxPayloadBytes)) {
    await retry(
      () => postJson(config.ingestUrl, payload, {}, timeoutMs, { compression }),
      { retries: config.maxRetries, budget: globalRetryBudget }
    )
  }
}
  • Payload Splitting: Splits large batches to fit maxPayloadBytes
  • Compression: gzip/brotli support (plan-dependent)
  • Timeout: Configurable request timeout (default 10s)
  • Self-Request Guard: Skips SDK's own ingestion requests

Memory Pressure Monitoring

Graceful degradation under heap pressure:

export class MemoryPressureMonitor {
  private readonly elevatedThreshold = 0.7  // 70%
  private readonly criticalThreshold = 0.9 // 90%

  getState(): MemoryPressureState {
    const heapUtilization = mem.heapUsed / mem.heapTotal
    if (heapUtilization >= 0.9) return { level: 'critical', ... }
    if (heapUtilization >= 0.7) return { level: 'elevated', ... }
    return { level: 'normal', ... }
  }
}
Critical Pressure: When heap utilization exceeds 90%, batch sending is paused to prevent OOM crashes.

Configuration Reference

Complete reference for all configuration options, environment variables, and plan tiers.

SDK Init Options

Option Type Default Description
apiKey string - Required. Project API key
service string "unknown-service" Service name for telemetry grouping
environment string "production" Deployment environment
release string "0.0.0-unknown" Version/release identifier
enableErrors boolean true Enable error tracking
enablePerformance boolean true Enable request monitoring
enableTracing boolean true Enable distributed tracing
enableMetrics boolean true Enable metrics collection
sampleRate number 1.0 Client-side sampling (0-1)
maxBreadcrumbs number 100 Max breadcrumbs per request
debug boolean false Enable debug logging
logLevel string "warning" Min log level (debug/info/warning/error/fatal)
baseUrl string - Custom server URL override
shutdownTimeoutMs number 10000 Graceful shutdown timeout (ms)

Transport Options

Option Type Default Description
transport.batchSize number 100 Events per batch
transport.flushIntervalMs number 5000 Flush interval (ms)
transport.maxRetries number 3 Max retry attempts
transport.timeoutMs number 10000 Request timeout (ms)
transport.compression string "none" Payload compression (gzip/brotli/none)
transport.maxPayloadBytes number 2000000 Max payload size (bytes)
transport.maxConcurrentSends number 3 Max in-flight batch sends

Environment Variables

Variable Description
PULSE_API_KEY Alternative to passing apiKey in options
PULSE_BASE_URL Custom server URL
PULSE_ENVIRONMENT Override environment
SDK_BASE_URL Legacy base URL variable

Production Configuration Example

await createSDK({
  apiKey: process.env.PULSE_API_KEY,
  service: 'payments-service',
  environment: process.env.NODE_ENV ?? 'production',
  release: process.env.IMAGE_VERSION ?? '0.0.0',
  enableErrors: true,
  enablePerformance: true,
  enableTracing: true,
  enableMetrics: true,
  sampleRate: 1.0,
  maxBreadcrumbs: 200,
  debug: process.env.NODE_ENV === 'development',
  logLevel: process.env.LOG_LEVEL ?? 'warning',
  transport: {
    batchSize: 50,
    flushIntervalMs: 5000,
    maxRetries: 3,
    timeoutMs: 10000,
    compression: 'gzip',
    maxConcurrentSends: 3,
  },
  beforeSend: (event) => {
    // Filter sensitive events
    if (event.type === 'error' && event.message.includes('password')) {
      return null
    }
    return event
  },
})

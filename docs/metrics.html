Metrics System

Metrics System

Client-side aggregation for counters, gauges, and histograms with percentile computation.

Metric Types

Counter

Monotonically increasing value - ideal for request counts, error counts:

// Increment counter by 1 (default)
incrementCounter('http.requests')

// Increment by custom value
incrementCounter('http.requests', 1, { method: 'GET', status: '200' })

// Direct capture
captureMetric('http.requests', 1, 'counter', { tags: { method: 'GET' } })

Gauge

Point-in-time value - ideal for memory usage, active connections:

setGauge('memory.heap.used', 150000000, { unit: 'bytes' })
setGauge('active.connections', 42, { service: 'api' })

Histogram

Distribution of values - ideal for latency, request size:

recordHistogram('http.request.duration', 125.5, { method: 'GET' }, 'ms')
recordHistogram('request.size', 2048, { endpoint: '/api/users' }, 'bytes')

Up-Down Counter

Can increase or decrease - ideal for queue depth, active users:

addUpDownCounter('queue.depth', 1, { queue: 'default' })
addUpDownCounter('queue.depth', -1, { queue: 'default' })

Client-Side Aggregation

The metrics registry performs client-side aggregation before export:

class HistogramAggregator {
  record(value: number, labels: MetricLabels): void {
    // Store raw values
    this.values.push(value)
    this.count++
    this.sum += value
  }

  flush(): AggregatedMetric[] {
    const sorted = [...this.values].sort((a, b) => a - b)
    return {
      count: this.count,
      sum: this.sum,
      min: sorted[0],
      max: sorted[sorted.length - 1],
      p50: percentile(sorted, 50),
      p90: percentile(sorted, 90),
      p95: percentile(sorted, 95),
      p99: percentile(sorted, 99),
      avg: this.sum / this.count,
    }
  }
}

Percentile Computation

Histograms automatically compute percentiles:

  • p50 (median): 50% of values are below this
  • p90: 90% of values are below this
  • p95: 95% of values are below this
  • p99: 99% of values are below this

Cardinality Protection

Prevents label explosion that could cause memory issues:

const MAX_CARDINALITY = 1000 // Per metric

record(value, labels) {
  const key = this.labelKey(labels)
  if (this.labelSets.size >= this.maxCardinality && !this.labelSets.has(key)) {
    // Drop - cardinality limit reached
    return
  }
}

Flush Intervals

Metrics are aggregated and exported at regular intervals:

Metric Type Flush Interval Aggregation
Counter 10 seconds Sum over window
Histogram 10 seconds Percentiles
Gauge 10 seconds Last value
Up-Down Counter 10 seconds Current value
